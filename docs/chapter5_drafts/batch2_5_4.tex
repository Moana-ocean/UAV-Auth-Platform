\section{Normal Authentication Results}
\label{sec:ch5-normal-auth}

Normal authentication was evaluated with the \texttt{valid\_active} scenario across identity counts $n \in \{10,50,100,250,500\}$ and concurrency levels $c \in \{1,5,10,25,50\}$ for each mechanism (50 runs; steps 3--52 of the matrix). Table~\ref{tab:ch5-acceptance} reports acceptance outcomes after excluding warm-up attempts.

For the X.509 baseline, every scalability run achieved full acceptance: $n_{\mathrm{accepted}} = 30$ of $n_{\mathrm{measured}} = 30$ with zero false rejections and zero timeouts across all 25 configurations (750/750 measured repetitions in aggregate).

For the blockchain mechanism, all 25 scalability runs likewise achieved full acceptance: $n_{\mathrm{accepted}} = 30$ per run, zero false rejections, and zero authentication timeouts (750/750 aggregate). Three cells initially recorded RPC-timeout false rejections during the first matrix pass; those cells were re-executed after multi-endpoint RPC failover was enabled and then met the acceptance criterion (see \texttt{07\_data\_quality\_report.md}).
